## Paper Assistant 的拉取命令
- `/git help pull`：查看参数与协作分支限制。
- `/git pull origin 分支名`：创建远端合并审阅任务，不代表文件已经更新。
- 结果面板的 `Review merge task`：直接打开同一个共享任务窗口。
- 状态和应用权限由服务器提供；切换工作区后，旧请求结果不会写入新工作区的结果面板。
