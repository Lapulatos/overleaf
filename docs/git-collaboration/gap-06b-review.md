# G06b 备份恢复代次验收

状态：已实现并部署隔离 18082，现有 Chrome A / Firefox B 交互通过。恢复产生新的私有论文项目，原项目不被替换。

## 实现
- 校验备份清单及全部文件哈希，分配新的项目、文件夹、文档、附件 ID 和更高工作区代次。
- 恢复当前正文、已删除文档、附件、完整历史、评论、聊天、历史标签、Git 分支及暂存状态。
- 旧任务仅保留证据；凭据、自动同步和成员权限不自动恢复。子工作区验证、落盘后才发布父项目。
- 中断保留失败代次，不在原失败代次继续写入；再次恢复分配全新身份，避免迟到写入污染新项目。

## 边界
只支持恢复服务端保留的可信备份，不提供外部 ZIP 上传恢复。备份上限 1 GiB / 100000 文件，执行限时 5 分钟。未验收超大项目、进程强杀、Mongo 故障、评论锚点编辑全路径。自动任务保持停用，恢复不是旧项目原位回滚。正式论文、远端仓库及 18080/18081 未修改。
